写真から3Dメッシュを生成

生成処理は利用者のブラウザー内で行う方式です。写真をこのサイトのサーバーへ送らず、生成用の有料GPUサーバーも使いません。端末の性能・対応ブラウザーによって処理時間や結果が変わります。

写真生成ツールを開く（WebSfM）

WebSfMは別サイトで動作するオープンソースのベータ版です。フィギュアの細部まで再現できるかは、写真と端末によって異なります。画像からの再構成は、髪の細い束・透明部品・光沢面・隠れた部分を完全には復元できません。

撮影の目安

  • フィギュアを固定し、カメラを回して周囲を撮ります。正面・斜め・側面・背面を複数の高さから撮影します。
  • 隣り合う写真で見える範囲を十分に重ね、全体で40〜80枚ほどを目安にします。
  • 距離・照明を一定にし、ピントを合わせます。強い反射や影、背景の変化は避けます。
  • 上下や後ろ側など、隠れている面も撮影します。支えや台は後で切り取る必要がある場合があります。

物体が動く、背景が写真ごとに大きく変わる、表面に模様が少ない場合は、カメラ位置の推定や形状復元に失敗することがあります。

生成したモデルを動かしてAR表示

  1. WebSfMで写真を読み込み、位置合わせとメッシュ生成を行います。
  2. テクスチャ付きメッシュを glTF 形式で書き出します。関連する .bin と画像ファイルもまとめて保存してください。
  3. このページに戻り、ボーン設定ページで .gltf と関連ファイルを同時に選択します。関節を配置し、ウェイトを生成してGLBを書き出します。
  4. モデル切替・関節操作・ARページで書き出したGLBを読み込み、動作を調整してAR表示します。
写真 → メッシュ → ボーン・ウェイト → 動作・AR
端末について

WebSfMはChromium系ブラウザー（Chrome / Edge）を推奨しています。WebGPU対応の有無で処理速度が変わり、Safariで実写真を処理する動作は未確認です。まずPCのChromeまたはEdgeで少ない枚数から試してください。処理が止まる、ページが再読み込みされる場合は画像枚数や解像度を下げてください。
